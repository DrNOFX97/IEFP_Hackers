Nikto

Scanner de servidores web — milhares de testes de ficheiros perigosos, versões desatualizadas e misconfigurações

🔗 Site oficial 📖 Documentação 📦 GitHub

O que é o Nikto?

O Nikto é um scanner open source de servidores web que realiza testes abrangentes contra servidores web para múltiplos itens potencialmente perigosos. Verifica mais de 7000 ficheiros e programas perigosos, testa versões desatualizadas de mais de 1250 servidores, e identifica problemas específicos de versão em mais de 270 servidores [citation:8].

É construído sobre o LibWhisker (de RFP) e corre em qualquer plataforma com Perl. Suporta SSL, proxies, autenticação de host, evasão de IDS, e pode ser atualizado automaticamente a partir da linha de comandos [citation:1]. O Nikto não foi desenhado para ser furtivo — testa o servidor no menor tempo possível e é óbvio nos logs ou para IPS/IDS [citation:8].

O Que o Nikto Verifica

Os testes do Nikto focam-se em problemas de segurança geralmente considerados perigosos [citation:13]:

CategoriaDescrição
MisconfiguraçõesConfigurações incorretas de servidor e software .
Ficheiros padrãoFicheiros e programas instalados por defeito que não deviam estar acessíveis .
Ficheiros insegurosFicheiros e programas com permissões ou conteúdos perigosos .
Versões desatualizadasServidores e programas com versões conhecidamente vulneráveis .
Ficheiros perigososBackups, ficheiros de configuração e outros recursos sensíveis expostos .
Indicadores de LFILocal File Inclusion e outros problemas conhecidos (novo em 2.6.0) [citation:4][citation:15].

Novidades nas Versões Recentes

O Nikto tem evoluído significativamente. As versões 2.5.0 e 2.6.0 trouxeram melhorias importantes [citation:2][citation:4]:

VersãoDestaques
2.5.0 Suporte IPv6, flag -usecookies, -followredirects, -noslash, centenas de atualizações de testes .

Exemplos de Uso — do Básico ao Avançado

1. Verificar versão e ajuda

Setup
nikto -Version
nikto -Help

Confirma a versão instalada e lista todas as flags .

2. Scan básico de um servidor web

Básico
nikto -h http://192.168.1.10

Testa o servidor na porta 80 com todos os plugins por defeito [citation:3].

3. Scan HTTPS

Básico
nikto -h https://192.168.1.10 -ssl

Força a ligação SSL. O Nikto também deteta HTTPS automaticamente, mas -ssl garante .

4. Scan de porta não padrão

Básico
nikto -h 192.168.1.10 -p 8080

Testa o servidor na porta 8080 em vez da 80 [citation:9].

5. Testar apenas os portos HTTP(S)

Básico
nikto -h 192.168.1.10 -findonly

Só descobre os portos HTTP(S) e reporta o header Server, sem fazer scan de segurança [citation:1].

6. Vhost — múltiplos sites no mesmo IP

Básico
nikto -h 192.168.1.10 -vhost app.example.com

Envia o header Host: app.example.com para atingir a aplicação correta quando o servidor aloja vários sites [citation:9].

7. Tuning — selecionar categorias de testes

Tuning
nikto -h 192.168.1.10 -Tuning x

Testa apenas XSS. As categorias disponíveis incluem: 0 (File Upload), 1 (Interesting File), 2 (Misconfiguration), 3 (Info Disclosure), 4 (Injection), x (XSS), s (SQL Injection) [citation:17].

8. Combinar categorias de tuning

Tuning
nikto -h 192.168.1.10 -Tuning 2,3

Executa apenas testes de misconfiguration e information disclosure — reduz tempo e ruído [citation:17].

9. Evasão de IDS/IPS

Evasão
nikto -h 192.168.1.10 -evasion 1

Random URI encoding (non-UTF8). Outras técnicas: 2 (directory self-reference /./), 3 (premature URL ending), 4 (prepend long random string), 5 (fake parameter), 6 (TAB as request spacer), 7 (change case of URL), 8 (Windows directory separator) [citation:1].

10. Combinar técnicas de evasão

Evasão
nikto -h 192.168.1.10 -evasion 1,3,6

Múltiplas técnicas concatenadas com vírgulas. Aumenta a probabilidade de bypass de WAF [citation:17].

11. Output em HTML

Output
nikto -h 192.168.1.10 -o scan.html -Format html

Gera relatório HTML para visualização ou partilha [citation:17].

12. Output em CSV (para triage)

Output
nikto -h 192.168.1.10 -o scan.csv -Format csv

CSV é ideal para importar em folhas de cálculo ou bases de dados [citation:9].

13. Output em XML (para ferramentas)

Output
nikto -h 192.168.1.10 -o scan.xml -Format xml

XML para integração com ferramentas de reporting automatizadas [citation:9].

14. Múltiplos formatos por scan (2.6.0)

Output
nikto -h 192.168.1.10 -o scan.txt -Format txt,xml,json

Novo em 2.6.0: gera vários formatos numa só execução [citation:4].

15. Autenticação HTTP Basic

Auth
nikto -h 192.168.1.10 -id admin:password123

Credenciais para HTTP Basic Auth. Formato: id:password ou id:password:realm [citation:13].

16. Limitar tempo de scan

Tuning
nikto -h 192.168.1.10 -maxtime 10m

Máximo de 10 minutos por host. Útil para scans amplos onde não queres ficar preso num servidor lento [citation:9].

17. Pausa entre testes (evitar rate-limit)

Tuning
nikto -h 192.168.1.10 -Pause 1

Pausa de 1 segundo entre testes. Reduz a probabilidade de bloqueio por rate-limiting [citation:9].

18. Scan de ficheiro com múltiplos hosts

Tuning
nikto -h targets.txt

targets.txt com um host por linha. Também aceita output do nmap -oG [citation:13].

19. Usar proxy

Tuning
nikto -h 192.168.1.10 -useproxy http://127.0.0.1:8080

Rotear tráfego por proxy (ex: Burp Suite, ZAP) para inspeção ou anonimato [citation:9].

20. Atualizar base de dados

Setup
nikto -update

Atualiza os plugins e checks a partir do servidor CIRT. Essencial antes de scans importantes [citation:17].

Interpretação de Output

O output do Nikto segue um formato consistente. Exemplo de findings comuns [citation:17]:

FindingSignificado
Server: Apache/2.4.6Versão identificada — verifica CVEs conhecidos .
Directory listing found at /manual/Indexação de diretórios ativa — expõe ficheiros .
phpinfo.php existsFicheiro de diagnóstico exposto — revela credenciais e config .
Wordpress login foundAplicação identificada — aprofunda com wpscan .

Cheat Sheet rápido

-h http://target Scan básico
-ssl Forçar HTTPS
-p 8080 Porta específica
-vhost app.com Host virtual
-Tuning 2,3 Misconfig + Info Disclosure
-evasion 1,3,6 Bypass IDS/WAF
-o scan.html Output HTML
-id admin:pass Autenticação Basic
💡 Dica: O Nikto é barulhento por natureza. Para scans discretos, usa -Pause para espaçar pedidos e -maxtime para limitar duração. Antes de scans importantes, atualiza a base com nikto -update — a eficácia depende inteiramente de checks atualizados [citation:17].
⚠️ Aviso legal: O Nikto faz milhares de pedidos ao servidor e é imediatamente visível nos logs ou para um IDS/IPS [citation:8]. Usar contra sistemas sem autorização explícita por escrito é ilegal. O volume de pedidos pode causar degradação de performance ou ser interpretado como ataque. Usa apenas em sistemas que possuis ou em testes com scope claramente definido.
