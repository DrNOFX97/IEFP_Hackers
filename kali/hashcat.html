O que é o Hashcat?

O Hashcat é o cracker de passwords acelerado por GPU mais rápido do mundo. Usa o poder de processamento da placa gráfica (ou CPU como fallback) para realizar ataques de dicionário, máscara e baseados em regras contra hashes de passwords. Suporta centenas de tipos de hash e é a ferramenta de eleição para recuperação de passwords em testes de penetração e forense digital.

Os hashes são extraídos de sistemas comprometidos — bases de dados, ficheiros /etc/shadow, dumps de memória ou capturas de rede. A partir daí, o Hashcat testa candidatos offline, sem interagir com o sistema alvo, o que o torna extremamente rápido e seguro para o testador.

Modos de Ataque do Hashcat

O Hashcat suporta vários modos de ataque, selecionados pela flag -a:

Modo Nome Descrição
-a 0 Straight / Dictionary Ataque de dicionário — testa cada palavra de uma wordlist.
-a 1 Combination Combina palavras de duas ou mais wordlists.
-a 3 Brute-force / Mask Força bruta por padrão conhecido (ex: 4 dígitos).
-a 6 Hybrid Wordlist + Mask Adiciona uma máscara a cada palavra da wordlist (ex: palavra?d?d).
-a 7 Hybrid Mask + Wordlist Máscara antes da palavra da wordlist (ex: ?d?d palavra).

Hash Modes Essenciais

A flag -m define o algoritmo do hash. O Hashcat suporta mais de 350 modos:

Modo Algoritmo Uso comum
-m 0 MD5 Hashes antigos, aplicações web legacy
-m 100 SHA1 Hashes de sistemas Linux antigos, Git
-m 1000 NTLM Passwords Windows
-m 1800 sha512crypt Hashes Linux modernos (/etc/shadow)
-m 3200 bcrypt Hashes lentos (intencionalmente difíceis)
-m 13100 Kerberos TGS-REP Ambientes Active Directory
-m 22000 WPA-PBKDF2-PMKID+EAPOL Redes Wi-Fi WPA/WPA2

Exemplos de Uso — do Básico ao Avançado

1. Verificar GPU e dispositivos

Setup
hashcat -I

Lista os dispositivos OpenCL/CUDA detetados. Confirma se a GPU está a ser usada.

2. Benchmark de performance

hashcat -b

Executa um benchmark rápido para medir hashes/segundo por algoritmo.

3. Ataque de dicionário básico (MD5)

Dicionário
hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

Testa cada palavra do rockyou.txt contra hashes MD5.

4. Ataque com regras (mutações)

Regras
hashcat -m 1000 -a 0 hashes.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule

Aplica best64.rule para transformar cada palavra: capitalização, substituições (e→3, o→0), sufixos numéricos.

5. Ataque de máscara (padrão conhecido)

Máscara
hashcat -m 22000 -a 3 hash.hc22000 ?d?d?d?d?d?d?d?d

Força bruta para uma chave Wi-Fi de 8 dígitos numéricos.

Máscaras disponíveis: ?l (a-z), ?u (A-Z), ?d (0-9), ?s (símbolos), ?a (todos imprimíveis).

6. Ataque híbrido — wordlist + máscara

Híbrido
hashcat -m 1000 -a 6 hashes.txt rockyou.txt ?d?d?d?d

Adiciona 4 dígitos no final de cada palavra da wordlist (ex: password1234).

7. Mostrar passwords já cracked

hashcat -m 0 hashes.txt --show

Mostra os pares hash:password já recuperados, guardados no potfile.

8. Ataque a NTLM (Windows)

Windows
hashcat -m 1000 -a 0 ntlm_hashes.txt rockyou.txt

NTLM é o formato de hash de passwords do Windows.

9. Ataque a SHA1

Linux/Web
hashcat -m 100 -a 0 sha1_hashes.txt rockyou.txt

SHA1 é comum em aplicações web e sistemas Linux legados.

10. Ataque a bcrypt (lento, requer paciência)

Avançado
hashcat -m 3200 -a 0 bcrypt_hashes.txt rockyou.txt -r best64.rule

bcrypt é intencionalmente lento — resistente a GPU. Espera tempos longos mesmo com wordlist pequena.

11. WPA/WPA2 Wi-Fi — captura e conversão

Wi-Fi
hcxpcapngtool -o hash.hc22000 dump.pcapng

Converte uma captura .pcapng (PMKID ou handshake) para o formato .hc22000 que o Hashcat espera.

12. WPA/WPA2 — ataque com dicionário

Wi-Fi
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt

Testa cada palavra do dicionário contra a chave Wi-Fi capturada.

13. WPA/WPA2 — ataque com regras

Wi-Fi
hashcat -m 22000 hash.hc22000 rockyou.txt -r /usr/share/hashcat/rules/best64.rule

As regras aumentam drasticamente a taxa de sucesso — capitalização, substituições e sufixos.

14. WPA/WPA2 — máscara para routers padrão

Wi-Fi
hashcat -m 22000 -a 3 hash.hc22000 ?d?d?d?d?d?d?d?d

Muitos routers usam chaves numéricas de 8 dígitos por defeito.

15. Retomar sessão anterior

hashcat -m 22000 hash.hc22000 rockyou.txt --session=mysession --restore

Retoma um ataque interrompido, desde o ponto onde parou.

16. Guardar resultados em ficheiro

hashcat -m 1000 hashes.txt rockyou.txt -o cracked.txt

Escreve os pares hash:password descobertos para cracked.txt.

Workload Profile — Otimização de Performance

A flag -w controla a agressividade do uso da GPU. Valores mais altos = mais rápido, mas mais calor e ruído:

Perfil Descrição
-w 1 Baixo — uso mínimo de recursos
-w 2 Padrão — equilíbrio
-w 3 Alto — mais agressivo (recomendado para sessões dedicadas)
-w 4 Máximo — pode causar instabilidade térmica em GPUs fracas

Cheat Sheet rápido

-m 0 MD5
-m 1000 NTLM (Windows)
-m 22000 WPA/WPA2 (Wi-Fi)
-a 0 Dicionário
-a 3 Máscara / Força bruta
-a 6 Híbrido (wordlist + máscara)
-r best64.rule Regras de mutação
--show Ver resultados já crackeados
💡 Dica: Os resultados ficam guardados no potfile (~/.local/share/hashcat/hashcat.potfile). Podes reutilizá-los com --show ou --left para continuar ataques futuros sem repetir trabalho.
⚠️ Aviso legal: O Hashcat pode ser usado de forma legal e ilegal. Cabe-te garantir que o uso é legal. Obtém sempre permissão e aprovação antes de crackear passwords, e trata a informação obtida de forma ética. Se não tens a certeza se o uso é legal, não avances até confirmares — por exemplo, discutindo e validando o uso planeado com o departamento jurídico da tua organização.
