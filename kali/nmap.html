Nmap

Network Mapper — O scanner de rede e auditoria de segurança mais usado do mundo

🔗 Site oficial 📖 Documentação 📦 Download

O que é o Nmap?

O Nmap ("Network Mapper") é uma ferramenta open source para exploração de rede e auditoria de segurança. Foi projetado para escanear redes de forma rápida, embora funcione igualmente bem contra um único host. Usa pacotes IP brutos de formas engenhosas para determinar quais hosts estão disponíveis na rede, quais serviços (nome e versão) esses hosts oferecem, que sistemas operativos (e versões) executam, que tipo de filtros de pacotes/firewalls estão em uso, e dezenas de outras características.

Embora seja comumente usado para auditorias de segurança, administradores de sistemas e redes também o acham útil para tarefas de rotina como inventário de rede, gestão de agendas de atualização de serviços e monitorização de uptime de hosts ou serviços.

Como funciona a descoberta

O Nmap classifica cada porta escaneada num dos seguintes estados:

Estado Significado
open Uma aplicação está ativamente à escuta de conexões nessa porta.
closed A porta está acessível mas não há nenhuma aplicação à escuta. Pode abrir a qualquer momento.
filtered Um firewall, filtro ou obstáculo de rede está a bloquear a porta. O Nmap não consegue determinar se está aberta ou fechada.
unfiltered A porta responde aos probes do Nmap, mas não é possível determinar se está aberta ou fechada.
open|filtered O Nmap não consegue determinar se a porta está aberta ou filtrada.
closed|filtered O Nmap não consegue determinar se a porta está fechada ou filtrada.

Instalação

Linux (Debian/Ubuntu/Kali)

sudo apt-get update && sudo apt-get install nmap

macOS (Homebrew)

brew install nmap

Windows

Descarrega o instalador oficial em nmap.org/download e executa o nmap-<version>-setup.exe.

Exemplos de uso (do básico ao avançado)

1. Escaneamento básico de um host

Descoberta
nmap 192.168.1.1

Escaneia as 1000 portas mais comuns do host alvo. É o ponto de partida.

2. Escaneamento de uma sub-rede

nmap 192.168.1.0/24

Escaneia todos os hosts na sub-rede (notação CIDR). Útil para mapear a rede.

3. Descoberta de hosts ativos (Ping Sweep)

nmap -sn 192.168.1.0/24

Lista quais hosts estão online sem escanear portas. Rápido para inventário.

4. Deteção de versões de serviços

Deteção
nmap -sV 192.168.1.1

Além de listar portas abertas, identifica a versão do software em execução. Essencial para avaliação de vulnerabilidades.

5. Deteção de Sistema Operativo

nmap -O 192.168.1.1

Tenta determinar o sistema operativo do alvo com base nas respostas aos pacotes.

6. Escaneamento Stealth (TCP SYN)

Técnica
sudo nmap -sS 192.168.1.1

Também conhecido como half-open scan. Envia pacotes SYN sem completar o three-way handshake. Mais rápido e menos detetável que um scan TCP completo.

7. Escaneamento TCP Connect

nmap -sT 192.168.1.1

Completa o three-way handshake com cada porta. Mais detetável, mas mais fiável e não requer privilégios de root.

8. Escaneamento UDP

Técnica
sudo nmap -sU 192.168.1.1

Escaneia portas UDP (DNS, SNMP, DHCP, TFTP). Mais lento que TCP porque o UDP não tem handshake. Pode demorar até 18 horas sem otimização.

9. Escaneamento de portas específicas

nmap -p 80,443 192.168.1.1

Escaneia apenas as portas indicadas (separadas por vírgula).

10. Escaneamento de todas as portas

nmap -p- 192.168.1.1

Escaneia todas as 65535 portas. Mais demorado, mas não deixa nada por verificar.

11. Ignorar ping (hosts que bloqueiam ICMP)

nmap -Pn 192.168.1.1

Trata todos os hosts como online, mesmo que não respondam a ping. Útil quando há firewalls a bloquear ICMP.

12. Scan agressivo (tudo de uma vez)

Deteção
nmap -A -T4 scanme.nmap.org

Combina deteção de SO, versões, script scanning e traceroute. -T4 acelera a execução. Usa com cuidado em produção.

13. Mapear regras de firewall (ACK Scan)

nmap -sA 192.168.1.1

Envia pacotes apenas com flag ACK. Não descobre portas abertas, mas mapeia as regras de filtragem do firewall.

14. Scan de vulnerabilidades com NSE

Scripts
nmap --script vuln 192.168.1.1

Usa a categoria vuln do Nmap Scripting Engine para verificar vulnerabilidades conhecidas.

15. Enumerar diretórios web

Scripts
nmap -p 80 --script http-enum 192.168.1.1

Descobre diretórios e ficheiros comuns em servidores web.

16. Brute-force SSH com NSE

Scripts
nmap --script ssh-brute 192.168.1.1

Testa credenciais SSH com base em listas de utilizadores e passwords. Apenas em testes autorizados.

Cheat Sheet rápido

nmap -sn 10.0.0.0/24 Ping sweep — descobre hosts ativos
nmap -sV -sC 192.168.1.1 Versões + scripts default
nmap -p- -T4 192.168.1.1 Todas as portas, execução rápida
nmap -sU --top-ports 50 192.168.1.1 Top 50 portas UDP
nmap -O --osscan-guess 192.168.1.1 Deteção agressiva de SO
nmap -oN output.txt 192.168.1.1 Guardar resultado em ficheiro

Combinando flags — a fórmula do Nmap

Nmap + Alvo + Tipo + Portas + Deteção + Timing + Scripts + Evasão

Exemplo de um scan lento e minucioso:

nmap 192.168.10.50 -sT -p1-65535 --version-light --max-rate 5 --script=vulners -S 192.168.1.1
⚠️ Aviso legal: O Nmap é legal, mas escanear redes sem autorização explícita por escrito viola as leis de cibersegurança (GDPR e legislação local). Usa sempre em sistemas que possuis ou tens permissão para testar. O host scanme.nmap.org foi criado especificamente para prática.
