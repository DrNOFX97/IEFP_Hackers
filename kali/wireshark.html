O que é o Wireshark?

O Wireshark é o analisador de protocolos de rede líder mundial. Seja para resolver problemas de rede, aprender sobre redes ou investigar detalhes ao nível do pacote, o Wireshark dá-te a visibilidade e as ferramentas necessárias. É uma ferramenta open source, livre de qualquer custo de licença, mantida pela Wireshark Foundation, uma organização sem fins lucrativos.

Captura e inspeciona tráfego de rede em tempo real ou a partir de ficheiros guardados (PCAP/PCAPNG), suportando centenas de protocolos. É usado tanto para diagnóstico de rede como para investigações de segurança — deteção de malware, exfiltração de dados, análise forense e muito mais.

Duas Ferramentas, Um Propósito

O Wireshark vem com duas interfaces complementares:

Ferramenta Descrição
wireshark Interface gráfica completa (GUI). Ideal para análise visual, exploração de pacotes e trabalho interativo.
tshark Versão de linha de comandos. Essencial para automação, scripts e servidores headless (sem GUI).

Captura vs. Filtros de Visualização

Uma das distinções mais importantes no Wireshark é entre filtros de captura e filtros de visualização:

Tipo Quando Sintaxe Exemplo
Capture Filter Antes/durante a captura. Pacotes não correspondentes são descartados e nunca guardados. BPF (libpcap) host 10.0.0.5 and port 80
Display Filter Depois da captura. Apenas filtra o que é mostrado — os dados ficam todos guardados. Wireshark display http.request.method == "POST"
💡 Regra prática: Captura o mais amplamente possível (quando o scope permite). Os filtros de captura cortam o tamanho do PCAP, mas não podes recuperar pacotes descartados depois.

Exemplos de Uso — da Captura à Extração

1. Captura básica de tráfego

Captura
wireshark -i eth0

Inicia o Wireshark na interface eth0. Na GUI, basta selecionar a interface e clicar em Start.

2. Capturar apenas tráfego HTTP/HTTPS

Captura
tshark -i eth0 -f 'port 80 or port 443'

Filtro de captura BPF para manter apenas tráfego web, reduzindo o tamanho do ficheiro.

3. Guardar captura em ficheiro

Captura
tshark -i eth0 -w /tmp/capture.pcap

Guarda a captura para análise posterior ou partilha com a equipa.

4. Ler um ficheiro PCAP

CLI
tshark -r /tmp/capture.pcap

Analisa um ficheiro existente sem capturar ao vivo.

5. Filtrar por IP

Display
ip.addr == 192.168.1.10

Mostra todo o tráfego de/para o IP especificado. Usa ip.src ou ip.dst para fixar direção.

6. Filtrar por protocolo

Display
http
dns
tls

Isola protocolos específicos. Combina com && ou ||.

7. Filtrar pedidos HTTP POST (formulários de login)

Display
http.request.method == "POST"

Caminho rápido para formulários de login e dados submetidos.

8. Encontrar credenciais em texto claro

Segurança
http.request.method == "POST" && http contains "password"

HTTP Basic Auth, FTP, Telnet enviam credenciais sem encriptação. Este filtro revela-as.

9. Seguir um stream TCP

Display
tcp.stream eq 3

Mostra todos os pacotes do stream #3. Na GUI: right-click > Follow > TCP Stream.

10. Detetar port scans

Segurança
tcp.flags.syn == 1 && tcp.flags.ack == 0

Isola pacotes SYN iniciais (sem ACK) — padrão típico de port scans.

11. Detetar DNS tunneling

Segurança
dns && frame.len > 100

Queries DNS anormalmente longas ou volumosas podem indicar tunneling ou exfiltração.

12. Extrair queries DNS únicas

CLI
tshark -r incident-capture.pcapng -Y "dns" -T fields -e dns.qry.name | sort -u

Extrai todos os nomes de domínio consultados — útil para identificar IOCs.

13. Exportar ficheiros transferidos via HTTP

CLI
tshark -r capture.pcap --export-objects http,./extracted/

Extrai todos os ficheiros reassembled de tráfego HTTP para uma pasta. Na GUI: File > Export Objects > HTTP.

14. Estatísticas de conversações

CLI
tshark -r capture.pcap -q -z conv,tcp

Ranking de quem falou com quem, ordenado por bytes/pacotes. Rápido para detetar transferências anómalas.

15. Hierarquia de protocolos

CLI
tshark -r capture.pcap -q -z io,phs

Breakdown do tráfego por protocolo. Confirma se há protocolos inesperados no segmento.

16. Extrair campos HTTP para scripts

CLI
tshark -r capture.pcap -Y 'http' -T fields -e http.request.method -e http.request.uri -e http.response.code -E separator=","

Output em CSV: método, URI e código de resposta para cada pedido HTTP.

17. Análise de handshake TLS (SNI)

Display
tls.handshake.type == 1

Mostra pacotes ClientHello — podes ver o SNI (nome do servidor) mesmo em tráfego encriptado.

Cheat Sheet rápido

ip.addr == 10.0.0.5 Tráfego de/para IP
tcp.port == 443 Filtrar por porta
http.request.method == "POST" Formulários de login
dns.qry.name contains "example.com" Queries DNS de um domínio
tcp.flags.syn == 1 && tcp.flags.ack == 0 Port scans / novas sessões
tcp.stream eq N Stream TCP específico
frame contains "password" Busca por string crua
tshark -r f.pcap -T fields -e ip.src Extrair campo para script
⚠️ Aviso legal e de privacidade: O Wireshark captura todo o tráfego na interface selecionada, que frequentemente contém informação pessoal identificável (PII). Capturar tráfego sem consentimento viola as leis de privacidade (RGPD, AI Act, etc.). Usa sempre em sistemas que possuis ou tens autorização explícita. Trata capturas exportadas como evidência sensível — guarda com acesso controlado e elimina após o período necessário.
