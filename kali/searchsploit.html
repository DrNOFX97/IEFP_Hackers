SearchSploit

Motor de busca offline do Exploit-DB — encontra exploits e PoCs sem ligação à Internet

🔗 Manual oficial 📖 Repositório Git 📦 GitHub (mirror)

O que é o SearchSploit?

O SearchSploit é a ferramenta de linha de comandos do Exploit Database (Exploit-DB), um projeto patrocinado pela Offensive Security. Permite pesquisar exploits, shellcodes e papers diretamente no arquivo local do Exploit-DB, sem necessidade de ligação à Internet. É essencial em ambientes isolados, air-gapped ou durante avaliações onde a conectividade é limitada [citation:1][citation:10][citation:17].

O Exploit-DB é o arquivo mais completo de exploits públicos e software vulnerável correspondente, reunindo contribuições diretas, mailing lists e outras fontes públicas. É um repositório de exploits e Proof-of-Concepts (PoCs), não de advisories — fornece dados acionáveis imediatamente [citation:1][citation:9]. A versão 4.0.1 do SearchSploit inclui suporte para papers do Exploit-DB, se configurados [citation:10].

Instalação

O SearchSploit está incluído no Kali Linux por defeito através do pacote exploitdb. Noutros sistemas, há várias formas de instalar [citation:5][citation:10]:

Kali Linux (pré-instalado)

searchsploit -h

Confirma a instalação. Se não existir (Kali Light), instala com:

sudo apt update && sudo apt install exploitdb

macOS (Homebrew)

brew update && brew install exploitdb

Linux genérico (Git)

git clone https://github.com/offensive-security/exploitdb.git /opt/exploitdb
sudo ln -sf /opt/exploitdb/searchsploit /usr/local/bin/searchsploit

Cria um link simbólico para não teres de indicar o caminho completo [citation:10][citation:19].

Flags Essenciais

O SearchSploit tem uma interface simples, mas as flags mudam radicalmente os resultados [citation:5][citation:7][citation:13]:

FlagDescrição
-t, --titlePesquisar apenas no título (padrão: título + caminho) — remove falsos positivos [citation:2][citation:5]
-e, --exactCorrespondência exata e ordenada no título (implica -t) [citation:7]
-s, --strictDesativa a pesquisa fuzzy para ranges de versões [citation:5][citation:7]
--excludeRemover resultados. Múltiplos termos separados por | [citation:2][citation:7]
--cvePesquisar por CVE específico (ex: --cve 2021-44228) [citation:3][citation:6]
--nmapAnalisar output XML do Nmap e procurar exploits para os serviços detetados [citation:3][citation:6][citation:19]
-m, --mirrorCopiar exploit para o diretório atual [citation:3][citation:4]
-p, --pathMostrar caminho completo do exploit (copia para clipboard) [citation:3][citation:7]
-x, --examineAbrir exploit no $PAGER para inspeção [citation:3][citation:11]
-w, --wwwMostrar URLs do Exploit-DB.com em vez de caminhos locais [citation:3][citation:5]
-j, --jsonOutput em formato JSON (para scripts) [citation:3][citation:6]
-u, --updateAtualizar a base de dados local [citation:3][citation:7]

Exemplos de Uso — do Básico ao Avançado

1. Pesquisa básica por keyword

Básico
searchsploit apache 2.4

Pesquisa "apache" e "2.4" no título e caminho. Os termos são combinados com AND por defeito [citation:11][citation:16].

2. Múltiplos termos (AND implícito)

Pesquisa
searchsploit afd windows local

Encontra exploits que contenham "afd", "windows" e "local" no título ou caminho [citation:1][citation:2].

3. Pesquisa apenas no título (remove ruído)

Pesquisa
searchsploit -t oracle windows

O -t reduz drasticamente os resultados ao ignorar o caminho do ficheiro. No exemplo, passa de 94 para 9 resultados [citation:2][citation:14].

4. Pesquisa exata e ordenada

Pesquisa
searchsploit -e "WordPress 4.1"

-e exige correspondência exata e na ordem. "WordPress 4.1" não encontraria "WordPress Core 4.1" [citation:5][citation:7].

5. Pesquisa estrita (sem fuzzy em versões)

Pesquisa
searchsploit -s "Samba 3.0.20"

O modo estrito desativa a deteção de ranges. "1.1" não seria encontrado em "1.0 < 1.3" [citation:5][citation:11].

6. Excluir resultados indesejados

Pesquisa
searchsploit linux kernel 3.2 --exclude="(PoC)|/dos/"

Remove exploits de Proof-of-Concept e Denial-of-Service. Múltiplos termos separados por | [citation:2][citation:7][citation:14].

7. Pesquisa por CVE

CVE
searchsploit --cve 2021-44228

Pesquisa o Log4Shell por CVE. Essencial quando tens o CVE de um scan de vulnerabilidades [citation:3][citation:6].

8. Ver caminho de um exploit específico

Ficheiros
searchsploit -p 39446

Mostra o caminho completo do EDB-ID 39446. Útil para localizar o ficheiro antes de o copiar [citation:3][citation:7].

9. Inspecionar exploit sem copiar

Ficheiros
searchsploit -x exploits/linux/local/39446.c

Abre o exploit no $PAGER (less). Lê sempre o código antes de o executar — nunca corras exploits cegamente [citation:11][citation:16].

10. Copiar exploit para o diretório atual

Ficheiros
searchsploit -m exploits/linux/local/39446.c

O -m copia o exploit para o diretório onde estás. É o primeiro passo para adaptar e testar [citation:3][citation:4][citation:16].

11. Ver URL do Exploit-DB em vez do caminho local

Pesquisa
searchsploit -w --cve 2024-6387

Mostra o URL direto para a página do Exploit-DB. Útil para partilhar referências com a equipa [citation:3][citation:5].

12. Output JSON para scripting

Scripting
searchsploit -j apache 2.4.49 | jq

Output estruturado em JSON, processável com jq para filtragem e automação [citation:3][citation:6].

13. Integração com Nmap — descoberta automática

Workflow
nmap -sV 192.168.1.10 -oX scan.xml
searchsploit --nmap scan.xml

O --nmap analisa o XML do Nmap e procura exploits para cada serviço e versão detetados [citation:3][citation:6][citation:19].

14. Atualizar a base de dados

Setup
searchsploit -u

Atualiza o arquivo local. No Kali, o pacote é atualizado semanalmente; via Git/Homebrew, diariamente [citation:7][citation:16].

Interpretação do Output

O output do SearchSploit segue um formato consistente. Aprender a ler os caminhos é essencial [citation:11]:

CaminhoSignificado
windows/remote/Exploit remoto contra Windows
windows/local/Escalação de privilégios local em Windows (requer shell prévia) [citation:11]
linux/remote/Exploit remoto contra Linux
linux/local/Escalação de privilégios local em Linux
.rbMódulo Metasploit (Ruby) — pode ser usado diretamente no msfconsole [citation:11]
.pyScript Python — requer Python e adaptação [citation:11]
.cCódigo C — requer compilação [citation:11]
.txtPoC em texto ou instruções

Cheat Sheet rápido

searchsploit apache 2.4 Pesquisa por keyword
searchsploit -t oracle Só títulos (menos ruído)
searchsploit -e "Struts 2" Correspondência exata
searchsploit --cve 2021-44228 Pesquisa por CVE
searchsploit --nmap scan.xml Integração com Nmap
searchsploit -m 39446 Copiar exploit localmente
searchsploit -x 39446 Inspecionar código
searchsploit -u Atualizar base de dados
💡 Dica: A qualidade do resultado depende da especificidade dos termos. Em vez de pesquisares "apache", pesquisa "apache 2.4.49" — a versão exata reduz de milhares para dezenas de resultados. E lê sempre o exploit antes de o correr: muitos são PoCs incompletos, requerem modificação, ou visam versões ligeiramente diferentes [citation:11][citation:16].
⚠️ Aviso legal: O SearchSploit apenas pesquisa exploits publicados — não os executa nem testa alvos. No entanto, baixar e executar exploits contra sistemas sem autorização explícita por escrito é ilegal. O Exploit-DB contém código que pode causar danos. Usa apenas em sistemas próprios, laboratórios isolados ou engajamentos com scope definido. A existência de um exploit público não significa que o alvo seja vulnerável — valida sempre [citation:6][citation:17].
