Burp Suite

A plataforma integrada para testes de segurança em aplicações web

🔗 Site oficial 📖 Documentação 📦 Download Community

O que é o Burp Suite?

O Burp Suite é uma plataforma integrada para realizar testes de segurança em aplicações web. Funciona como um proxy de interceção, colocando-se entre o browser e o servidor para analisar e manipular o tráfego web, permitindo a descoberta de vulnerabilidades . As suas ferramentas operam de forma integrada — podes passar pedidos interessantes entre ferramentas à medida que o trabalho avança.

A versão Community Edition é gratuita e inclui Proxy, Repeater e Intruder (com limitações). A Professional Edition adiciona o Scanner automatizado e Intruder completo. A PortSwigger mantém duas décadas de desenvolvimento com foco em testes manuais e automação assistida .

Ferramentas Principais do Burp Suite

O Burp organiza a funcionalidade em ferramentas especializadas que trabalham em conjunto:

Ferramenta Descrição
Proxy Proxy de interceção man-in-the-middle. Permite intercetar, inspecionar e modificar tráfego HTTP/HTTPS em ambas as direções.
Repeater Manipulação e reenvio manual de mensagens individuais, com análise das respostas.
Intruder Ataques automatizados e personalizados contra aplicações web — brute-force, fuzzing, enumeração.
Scanner Scanner de vulnerabilidades automatizado (apenas Professional). Rastreia conteúdo e audita vulnerabilidades.
Target / Site map Informação detalhada sobre as aplicações alvo e mapeamento da superfície de ataque visível.
Decoder Codificação e descodificação manual ou automática de dados (Base64, URL, Hex).
Comparer Comparação visual ("diff") entre dois itens de dados, como pares de mensagens HTTP.
Sequencer Análise da qualidade de aleatoriedade em tokens de sessão e dados imprevisíveis.
Logger Registo e análise do tráfego HTTP gerado pelo Burp Suite.
Collaborator Identificação de vulnerabilidades out-of-band (OAST).
DOM Invader Deteção de vulnerabilidades DOM XSS e prototype pollution.

Burp's Browser

O Burp inclui um browser pré-configurado para funcionar com a funcionalidade completa do Burp Suite desde o primeiro momento. A partir da versão 2026.7.2, o browser integrado foi renomeado de Chromium para Burp Browser. Basta clicar em "Open Browser" na aba Proxy para iniciar.

Exemplos de Uso — do Básico ao Avançado

1. Iniciar o Burp e abrir o browser

Proxy
burpsuite

Inicia o Burp Suite. Depois, vai a Proxy > Intercept e clica em Open Browser.

2. Intercetar tráfego HTTP

Proxy
Proxy > Intercept > Intercept is on

Com a interceção ligada, cada pedido do browser é pausado para revisão. Clica Forward para enviar ao servidor.

3. Ver histórico HTTP

Proxy > HTTP history

Registo completo de todo o tráfego. Clica em qualquer entrada para ver o pedido e resposta completos.

4. Definir scope (âmbito)

Reconhecimento
Target > Site map > right-click host > Add to scope

Define o âmbito para focar o teste. Filtra o ruído de terceiros e evita testes acidentais fora do scope.

5. Modificar pedido (ex: manipulação de preço)

Proxy

Com interceção ativa, localiza o parâmetro no pedido intercetado e edita-o:

productId=1&quantity=1&price=100 → productId=1&quantity=1&price=1

Exemplo clássico de teste de lógica de negócio.

6. Enviar pedido para Repeater

Repeater
Proxy > HTTP history > right-click > Send to Repeater

Permite manipular e reenviar pedidos individuais repetidamente, analisando cada resposta.

7. Testar variações de parâmetros no Repeater

Repeater
GET /product?productId=1
GET /product?productId=2
GET /product?productId=999

Modifica o valor, clica Send, revê a resposta. Repete para testar diferentes inputs.

8. Configurar Match and Replace

Proxy
Proxy > Match and replace > Add

Adiciona regras para modificar automaticamente pedidos e respostas. Útil para spoofing de IP ou headers.

X-Custom-IP-Authorization: 127.0.0.1

Exemplo: adicionar header para bypass de autenticação baseada em IP.

9. Enviar pedido para Intruder

Intruder
Proxy > HTTP history > right-click > Send to Intruder

Prepara o pedido para ataque automatizado.

10. Configurar posições de payload no Intruder

Intruder
Intruder > Positions > Clear §

Remove marcadores existentes. Seleciona o parâmetro a atacar e clica Add §.

11. Tipos de ataque do Intruder

Intruder
  • Sniper — Um payload set, uma posição de cada vez
  • Battering ram — Um payload set, todas as posições iguais
  • Pitchfork — Múltiplos payload sets, posições em paralelo
  • Cluster bomb — Múltiplos payload sets, todas as combinações.

12. Extrair dados úteis (Grep - Extract)

Intruder
Intruder > Options > Grep - Extract > Add

Configura a extração de dados das respostas — password hints, títulos de página, roles de utilizadores.

13. Passively scan (Community)

Scanner
Dashboard > Issue activity

O Burp Community faz scanning passivo automático — sinaliza issues no histórico do proxy.

14. Active scan (Professional)

Scanner
Target > Site map > right-click host > Actively scan this host

Disponível apenas na Professional Edition. Rastreia e audita vulnerabilidades automaticamente.

15. Gerar PoC de CSRF

Scanner
Proxy > HTTP history > right-click > Engagement tools > Generate CSRF PoC

Gera HTML de prova de conceito para ataques CSRF.

16. Usar DOM Invader

Scanner

Ferramenta integrada para deteção de DOM XSS. Injeta um canary e identifica sinks controláveis.

DOM Invader > Inject canary

17. Burp AT (AI Agent — Professional)

Scanner

Disponível em public beta para utilizadores Professional. Agentes de IA executam tarefas dentro do Burp Suite usando o contexto do projeto e skills de pentesting.

Analyze the minified JavaScript loaded by this target...

Exemplo real: um pentester usou Burp AT contra 66.000 linhas de JavaScript minificado e encontrou uma vulnerabilidade crítica.

Cheat Sheet rápido

Ctrl+I Toggle interceção (Proxy)
Ctrl+R Send to Repeater
Ctrl+I (Repeater) Send to Intruder
Ctrl+Shift+E Encoder/Decoder
Proxy > Intercept Intercetar pedidos
Target > Site map Mapear aplicação
Right-click > Send to... Passar entre ferramentas
Dashboard > Issue activity Ver issues encontrados
💡 Dica: O Burp é modular — podes passar pedidos entre ferramentas à medida que trabalhas. Um pedido intercetado no Proxy pode ir para o Repeater para teste manual, ou para o Intruder para fuzzing, ou para o Scanner para auditoria automática.
⚠️ Aviso legal: O Burp Suite contém funcionalidades que podem danificar sistemas alvo. Testar vulnerabilidades envolve interagir com os alvos de formas não convencionais que podem causar problemas. Usa apenas em sistemas que possuis ou para os quais tens autorização explícita por escrito.
