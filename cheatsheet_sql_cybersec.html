PK
Chave Primária (PK) Chaves
PRIMARY KEYIdentifica cada linha de forma única
✔ ÚnicaDois registos nunca podem ter o mesmo PK
✔ NOT NULLNunca pode ser vazia ou nula
✔ ImutávelNão deve mudar após inserção
✔ SimplesIdealmente um único campo (não composta)
AUTO_INCREMENTMySQL gera PK automático: 1, 2, 3...
id INT PRIMARY KEY AUTO_INCREMENTDeclaração mais comum em CREATE TABLE
FK
Chave Estrangeira (FK) Chaves
FOREIGN KEYLiga duas tabelas por referência
REFERENCES tabela(col)Indica a PK da tabela pai
ON DELETE CASCADEApaga filhos se pai for apagado
ON DELETE SET NULLFK fica NULL se pai for apagado
ON UPDATE CASCADEActualiza FK se PK pai mudar
FOREIGN KEY (user_id) REFERENCES users(id)Exemplo completo de FK
Integridade referencialFK não pode apontar para PK inexistente

SELECT DISTINCT pais FROM usersSem duplicados

WHERE nome LIKE '%silva%'% = qualquer texto
WHERE id IN (1,2,3)Numa lista de valores
WHERE id BETWEEN 10 AND 20Intervalo inclusivo

JOI
JOINs — Juntar Tabelas DQL
SELECT u.nome, p.titulo FROM users u INNER JOIN posts p ON u.id = p.user_id INNER JOIN — só linhas com match nas duas tabelas
SELECT u.nome, p.titulo FROM users u LEFT JOIN posts p ON u.id = p.user_id LEFT JOIN — todos os users, NULL onde não há post
SELECT * FROM users WHERE id IN (SELECT user_id FROM posts) Subquery — users que têm posts (alternativa ao JOIN)
SELECT a.nome AS chefe, b.nome AS emp FROM users a JOIN users b ON b.manager_id = a.id SELF JOIN — tabela ligada a si própria (hierarquias)

DCL
DCL — GRANT & REVOKE DCL
CREATE USER 'app'@'localhost' IDENTIFIED BY 'pass'Criar utilizador
GRANT SELECT ON loja.* TO 'app'@'localhost'Dar permissão de leitura
GRANT ALL PRIVILEGES ON *.* TO 'admin'@'%'Todos os privilégios
REVOKE SELECT ON loja.* FROM 'app'@'localhost'Remover permissão
SHOW GRANTS FOR 'app'@'localhost'Ver permissões actuais
DROP USER 'app'@'localhost'Remover utilizador
FLUSH PRIVILEGESAplicar alterações
✔ Boas práticas: mínimo privilégio — app user só deve ter SELECT/INSERT/UPDATE
TCL
TCL — Transações TCL
START TRANSACTIONIniciar transação (ou BEGIN)
COMMITConfirmar e guardar todas as alterações
ROLLBACKCancelar e reverter tudo desde START
SAVEPOINT sp1Marcar ponto intermédio reversível
ROLLBACK TO SAVEPOINT sp1Reverter apenas até ao savepoint
RELEASE SAVEPOINT sp1Remover savepoint da sessão
SET autocommit = 0Desactivar commit automático
⚡ Transações garantem que operações são tudo-ou-nada (atomicidade ACID)
