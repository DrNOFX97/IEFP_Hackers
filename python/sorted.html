AULA 06 • ORDENAÇÃO

sorted()
Ordenar sem destruir

A função mais usada (e mais mal compreendida) do Python. Devolve uma nova lista, aceita qualquer iterável, e com key faz magia.

// 01 — Básico

O que faz

sorted() devolve uma nova lista ordenada a partir de qualquer iterável, sem modificar o original.

sorted(iteravel, *, key=None, reverse=False)
🔢

Exemplo básico

Nova lista, original intacto
nums = [3, 1, 4, 1, 5, 9, 2, 6]

sorted(nums) # [1,1,2,3,4,5,6,9]
print(nums) # [3,1,4,1,5,9,2,6] ← intacto

sorted(nums, reverse=True) # [9,6,5,4,3,2,1,1]

Funciona com qualquer iterável

sorted((3, 1, 2)) # [1,2,3] ← tupla → lista
sorted("cba") # ['a','b','c'] ← string
sorted({3, 1, 2}) # [1,2,3] ← set
sorted({"b": 2, "a": 1}) # ['a','b'] ← chaves do dict
💡
Sempre devolve lista

Independentemente do iterável de entrada, sorted() devolve sempre uma lista. Isto é uma garantia da linguagem.

// 02 — Confusão clássica

sorted() vs list.sort()

Esta é a distinção que cai sempre em exame. Devolve vs modifica.

📋

sorted(iteravel)

Built-in · devolve nova lista
  • Não modifica o original
  • Devolve nova lista
  • Aceita qualquer iterável
  • Uso: x = sorted(nums)
✏️

lista.sort()

Método · modifica no lugar
  • Modifica a lista original
  • Devolve None
  • Só funciona em listas
  • Uso: nums.sort()

⚠️
Armadilha clássica

nums = nums.sort() → nums fica None! sort() modifica no lugar e devolve None. Se atribuíres o resultado, perdes a lista.

// 03 — O parâmetro mais importante

key

key recebe uma função que transforma cada elemento antes de o comparar. É a base de toda a ordenação personalizada.

🔑

Sintaxe

Função de transformação
sorted(iteravel, key=funcao)

Exemplos com funções built-in

# por comprimento
palavras = ["python", "c", "java", "javascript", "go"]
sorted(palavras, key=len)
# ['c', 'go', 'java', 'python', 'javascript']

# por valor absoluto
nums = [-5, 3, -1, 4, -2]
sorted(nums, key=abs)
# [-1, -2, 3, 4, -5]

# ignorar maiúsculas
nomes = ["ana", "Bruno", "carla", "David"]
sorted(nomes, key=str.lower)
# ['ana', 'Bruno', 'carla', 'David']

key com lambda

# tuplos por um campo
pessoas = [("Ana", 25), ("Rui", 30), ("Sofia", 22)]
sorted(pessoas, key=lambda p: p[1])
# [('Sofia',22), ('Ana',25), ('Rui',30)]

# dicionário por valor
notas = {"Ana": 18, "Rui": 12, "Sofia": 20}
sorted(notas.items(), key=lambda x: x[1])
# [('Rui',12), ('Ana',18), ('Sofia',20)]
🧠
Regra mental

key responde à pergunta: "por que critério comparo?" A função devolve o valor que o Python vai usar para comparar.

// 04 — Vários critérios

Ordenação em cascata

Para ordenar por vários campos, devolve um tuplo na key.

🎯

Tuplo na key

1º critério, 2º critério, …
pessoas = [
    ("Ana", 25),
    ("Rui", 30),
    ("Ana", 22),
    ("Rui", 25),
]

# 1º por nome, 2º por idade
sorted(pessoas, key=lambda p: (p[0], p[1]))
# [('Ana',22), ('Ana',25), ('Rui',25), ('Rui',30)]

Misturar ascendente e descendente

# nome ascendente, idade descendente
sorted(pessoas, key=lambda p: (p[0], -p[1]))
# [('Ana',25), ('Ana',22), ('Rui',30), ('Rui',25)]
⚠️
reverse=True vs -p[1]

reverse=True inverte todos os critérios. Se queres inverter apenas um, usa - na key (só funciona para números).

// 05 — Avançado

Estabilidade e itemgetter

sorted() é estável: elementos iguais mantêm a ordem original. E itemgetter é mais rápido que lambda.

🏛️

Estabilidade

Empates mantêm ordem
dados = [("Ana", 25), ("Rui", 30),
         ("Sofia", 25), ("Pedro", 30)]

sorted(dados, key=lambda p: p[1])
# [('Ana',25), ('Sofia',25), ('Rui',30), ('Pedro',30)]
# ↑ Ana veio antes de Sofia — ordem original mantida

operator.itemgetter

from operator import itemgetter

pessoas = [("Ana", 25), ("Rui", 30), ("Sofia", 22)]

sorted(pessoas, key=itemgetter(1)) # por idade
sorted(pessoas, key=itemgetter(0, 1)) # nome, depois idade

attrgetter para objetos

from operator import attrgetter

class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

pessoas = [Pessoa("Ana", 25), Pessoa("Rui", 30)]
sorted(pessoas, key=attrgetter("idade"))

Ordenar dict por valor

d = {"b": 2, "a": 1, "c": 3}

sorted(d) # ['a','b','c'] — por chave
sorted(d.items(), key=lambda x: x[1]) # por valor
dict(sorted(d.items(), key=lambda x: x[1])) # de volta a dict
// 06 — Armadilhas

Erros comuns

Cinco armadilhas que apanham quase toda a gente.

❌

nums = nums.sort()

Fica None
nums = [3, 1, 2]
nums = nums.sort() # ❌ None

# ✅ usa sorted()
nums = sorted(nums)
🔤

Maiúsculas vs minúsculas

ASCII: 'Z' < 'a'
sorted(["Banana", "maçã"])
# ['Banana', 'maçã']

sorted(["Banana", "maçã"], key=str.lower)
# ['Banana', 'maçã'] ✅
🔀

Tipos mistos

TypeError
sorted([1, "a", 2]) # ❌ TypeError

# converte tudo para str
sorted([1, "a"], key=str)
🚫

None na lista

TypeError
sorted([3, None, 1]) # ❌ TypeError

# None no fim
sorted([3, None, 1],
    key=lambda x: (x is None, x))
🎭

reverse com múltiplos critérios

Inverte tudo
# reverse=True inverte TUDO
sorted(pessoas,
    key=lambda p: (p[0], p[1]),
    reverse=True)

# se queres inverter só um, usa -
sorted(pessoas,
    key=lambda p: (p[0], -p[1]))
🧠
Frase para memorizar

"sorted() devolve, sort() modifica. key transforma, reverse inverte."

// 07 — Exemplos práticos

Casos reais

Quatro exemplos que aparecem em código de produção.

01

Top 3 notas

Ordenar por valor e cortar os primeiros.

notas = {"Ana": 18, "Rui": 12, "Sofia": 20, "Pedro": 15, "Marta": 17}

top3 = sorted(notas.items(), key=lambda x: x[1], reverse=True)[:3]
# [('Sofia',20), ('Ana',18), ('Marta',17)]
02

Palavras por frequência

Contar e ordenar por número de ocorrências.

from collections import Counter

texto = "o gato viu o cão e o cão viu o gato"
contagem = Counter(texto.split())

mais_comuns = sorted(contagem.items(),
    key=lambda x: x[1], reverse=True)
# [('o',4), ('gato',2), ('viu',2), ('cão',2), ('e',1)]
03

Ficheiros por extensão e nome

Ordenação em cascata com tuplo.

ficheiros = ["a.txt", "b.py", "c.txt", "d.py"]

sorted(ficheiros, key=lambda f: (f.split(".")[-1], f))
# ['b.py', 'd.py', 'a.txt', 'c.txt']
04

Ignorar maiúsculas

Ordenação case-insensitive com str.lower.

nomes = ["ana", "Bruno", "carla", "David"]
sorted(nomes, key=str.lower)
# ['ana', 'Bruno', 'carla', 'David']
