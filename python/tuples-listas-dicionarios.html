// 02 — Listas

A estrutura mais flexível

Ordenada, mutável e aceita duplicados. É a estrutura de eleição para sequências que mudam.

📋

Criar, aceder e modificar

Bases
frutas = ["maçã", "banana", "pera"]
numeros = [1, 2, 3, 4, 5]
vazia = []
mista = [1, "texto", True, 3.14]

frutas[0] # "maçã"
frutas[-1] # "pera" (último)
frutas[1:3] # ["banana", "pera"]
frutas[::-1] # lista invertida

Métodos essenciais

frutas = ["maçã", "banana"]

frutas.append("pera") # acrescenta ao fim
frutas.insert(1, "uva") # insere na posição 1
frutas.remove("banana") # remove pelo valor
frutas.pop() # remove e devolve o último
frutas.pop(0) # remove e devolve o índice 0
frutas[0] = "kiwi" # substitui

Operações úteis

nums = [3, 1, 4, 1, 5]

len(nums) # 5
sum(nums) # 14
min(nums) # 1
max(nums) # 5
nums.count(1) # 2
nums.index(4) # 2
nums.sort() # ordena no lugar
sorted(nums) # devolve nova lista
⚠️
sort() vs sorted()

sort() modifica a lista original e devolve None. sorted() devolve uma nova lista ordenada, deixando a original intacta.

List comprehension

quadrados = [x**2 for x in range(5)] # [0,1,4,9,16]
pares = [x for x in range(10) if x % 2 == 0]
// 03 — Tuples

Imutáveis e leves

Uma tupla é como uma lista que não pode ser alterada. Mais rápida, mais leve, e pode ser usada como chave de dicionário.

🔒

Criar e aceder

Imutável
ponto = (3, 5)
cores = ("vermelho", "verde", "azul")
so_um = (42,) # ⚠️ vírgula obrigatória!
vazia = ()
sem_parenteses = 1, 2, 3 # também é tupla

ponto[0] # 3
ponto[-1] # 5

Porque usar tuplas?

🛡️

Imutabilidade

Protege os dados
coordenadas = (10, 20)
coordenadas[0] = 5 # ❌ TypeError
🔑

Chaves de dict

Hashable
mapa = {(0,0): "origem"}
# listas não podem ser chaves!

Unpacking

ponto = (3, 5)
x, y = ponto

a, b, c = 1, 2, 3

# com * para o resto
primeiro, *resto = [1, 2, 3, 4, 5]
# primeiro=1, resto=[2, 3, 4, 5]

# devolver múltiplos valores
def minmax(lista):
    return min(lista), max(lista)

lo, hi = minmax([3, 1, 4, 1, 5])
⚠️
Tupla de um elemento

(42) é um int, não uma tupla. Precisas de (42,) com a vírgula.

// 04 — Dicionários

Pares chave→valor

Estrutura ideal para mapear nomes a valores e para procuras rápidas O(1).

📖

Criar e aceder

Mapeamento
pessoa = {"nome": "Ana", "idade": 25}
vazio = {}
por_comp = {x: x**2 for x in range(5)}

pessoa["nome"] # "Ana"
pessoa["altura"] # ❌ KeyError
pessoa.get("altura") # None
pessoa.get("altura", 0) # 0

Modificar e iterar

pessoa["idade"] = 26 # atualiza
pessoa["profissao"] = "eng." # adiciona
del pessoa["cidade"] # remove
pessoa.pop("cidade", None) # remove sem erro

"nome" in pessoa # True

pessoa.keys() # dict_keys([...])
pessoa.values() # dict_values([...])
pessoa.items() # dict_items([...])

for chave, valor in pessoa.items():
    print(chave, valor)

update() — juntar dicionários

pessoa = {"nome": "Ana", "idade": 25}
pessoa.update({"idade": 26, "cidade": "Porto"})
# {"nome":"Ana", "idade":26, "cidade":"Porto"}

Padrão clássico: contar ocorrências

texto = "o gato viu o cão e o cão viu o gato"
contagem = {}

for palavra in texto.split():
    contagem[palavra] = contagem.get(palavra, 0) + 1

# {'o': 4, 'gato': 2, 'viu': 2, 'cão': 2, 'e': 1}
// 05 — Escolher

Qual usar?

A decisão depende do que precisas de fazer com os dados.

Precisas de...Usa
Sequência ordenada que mudaLista
Sequência ordenada que não mudaTupla
Procurar por nome/chaveDicionário
Garantir unicidadeSet
Chave compostaTupla dentro de dict
Fila / pilhaLista
Mapear → contarDicionário

Converter e zip

lista = [1, 2, 2, 3]

tuple(lista) # (1, 2, 2, 3)
set(lista) # {1, 2, 3} (remove duplicados)
list({1, 2, 3}) # [1, 2, 3]

nomes = ["Ana", "Rui", "Sofia"]
idades = [25, 30, 22]

pares = list(zip(nomes, idades))
# [('Ana',25), ('Rui',30), ('Sofia',22)]

d = dict(zip(nomes, idades))
# {'Ana':25, 'Rui':30, 'Sofia':22}
// 06 — Armadilhas

Erros comuns

Estes quatro erros aparecem em quase todos os iniciantes. Aprende a evitá-los.

🔗

Copiar listas

Referência vs cópia
a = [1, 2, 3]
b = a # MESMA lista!
b.append(4)
print(a) # [1,2,3,4]

c = a.copy() # cópia independente
🔑

Chave ausente

KeyError
d = {"a": 1}
d["b"] # ❌ KeyError
d.get("b") # None
d.get("b", 0) # 0
🔢

Tupla de 1 elemento

Vírgula obrigatória
t = (42) # int, não tupla!
t = (42,) # ✅ tupla
✂️

Modificar durante iteração

Comportamento imprevisível
nums = [1,2,3,4]
for n in nums:
    if n % 2 == 0:
        nums.remove(n) # ❌

# ✅ usa compreensão:
nums = [n for n in nums if n % 2]
🧠
Frase para memorizar

"Lista muda e cresce, tupla fica e protege, dicionário procura e encontra."
