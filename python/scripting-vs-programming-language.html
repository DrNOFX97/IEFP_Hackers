AULA 01 • FUNDAMENTOS

Scripting vs
Programming Language

A distinção mais mal-entendida da programação. Vamos ver porque é que toda a scripting language é uma programming language — mas o contrário nem sempre é verdade.

// 01 — Definições

Duas definições, uma verdade

Programming language é o guarda-chuva. Scripting language é uma especialização desse conceito, com contexto histórico próprio.

⚙️

Programming Language

Guardar-chuva
  • Qualquer linguagem formal para dar instruções ao computador
  • Tipicamente compilada para código máquina
  • Tipagem estática (verificada em compilação)
  • Performance elevada
  • Exemplos: C, C++, Java, Rust, Go
📜

Scripting Language

Especialização
  • Pensada para automatizar e "colar" componentes
  • Tipicamente interpretada ou JIT
  • Tipagem dinâmica (verificada em execução)
  • Ciclo de desenvolvimento rápido
  • Exemplos: Python, JavaScript, Ruby, Bash, Lua
💡
A verdade fundamental

Toda a scripting language é uma programming language. O contrário é que nem sempre é verdade. "Scripting" é um rótulo histórico/cultural, não uma categoria técnica rígida.

// 03 — A fronteira é difusa

Porque a divisão já não funciona

A separação clássica esbateu-se. Hoje, "scripting" e "programming" fazem exatamente as mesmas coisas.

🌐

JavaScript

"Scripting" que corre o mundo
  • Chamada scripting language
  • Mas corre Node.js, React, backends inteiros
  • É a linguagem mais usada do planeta
🐍

Python

"Scripting" que faz ML
  • Chamada scripting language
  • Usada em machine learning, data science, backends
  • Coisas pesadas e críticas
☕

Java

"Programming" com JIT
  • Chamada programming language
  • Mas usa JIT compilation e JVM
  • Tal como muitas scripting languages modernas
🔷

TypeScript

Onde fica?
  • É JavaScript... com tipagem estática
  • Scripting language ou programming language?
  • Prova que a divisão é arbitrária
⚠️
Cuidado com os rótulos

"Scripting language" é mais um rótulo histórico/cultural do que uma categoria técnica. Escolhe-se a linguagem pelo problema, não pelo rótulo.
