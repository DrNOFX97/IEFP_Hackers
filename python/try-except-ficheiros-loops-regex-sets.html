// 01 — Tratar erros

try / except

O programa não pode rebentar quando algo corre mal. O try/except apanha o erro e permite reagir com elegância.

💥

Sem try/except

O programa crasha
numero = int(input("Número: "))
# user escreve "abc" → ValueError → crash
🛡️

Com try/except

O programa aguenta
try:
    numero = int(input("Número: "))
    print(10 / numero)
except ValueError:
    print("Isso não é um número!")
except ZeroDivisionError:
    print("Não podes dividir por zero!")

Estrutura completa

try:
    # código que pode falhar
    ficheiro = open("dados.txt")
    conteudo = ficheiro.read()
except FileNotFoundError:
    print("Ficheiro não existe")
except Exception as e:
    print(f"Erro inesperado: {e}")
else:
    print("Correu tudo bem") # só se NÃO houve erro
finally:
    ficheiro.close() # corre SEMPRE
ErroQuando acontece
ValueErrorConversão falhada (int("abc"))
TypeErrorTipo errado ("a" + 1)
KeyErrorChave inexistente em dict
IndexErrorÍndice fora da lista
FileNotFoundErrorFicheiro não existe
ZeroDivisionErrorDivisão por zero
⚠️
Regras de ouro

Apanha erros específicos, não except: à solução. Um except: vazio esconde bugs — evita. Usa finally para limpar recursos.

// 02 — Ficheiros seguros

with open

Abrir ficheiros sem with é pedir problemas. O context manager garante que o ficheiro é fechado, aconteça o que acontecer.

❌

Sem with

Memory leak
f = open("dados.txt", "r")
conteudo = f.read()
f.close()
# se algo falhar antes, o ficheiro fica aberto!
✅

Com with

Fecho automático
with open("dados.txt", "r") as f:
    conteudo = f.read()
# ficheiro fechado automaticamente

Modos de abertura

ModoSignificado
"r"Ler (default) — erro se não existir
"w"Escrever — apaga o conteúdo existente
"a"Append — acrescenta ao fim
"x"Criar — erro se já existir
"rb" / "wb"Modo binário

Ler linha a linha (recomendado)

with open("dados.txt", "r") as f:
    for linha in f:
        print(linha.strip())
// 03 — Repetição

for vs while

O for usa-se quando sabes sobre o quê iteras. O while quando a repetição depende de uma condição.

🔁

for

Sabes sobre o quê
for fruta in ["maçã", "banana"]:
    print(fruta)

for i in range(5):
    print(i)

for i, fruta in enumerate(["a","b"]):
    print(i, fruta)
♾️

while

Depende de condição
senha = ""
while senha != "1234":
    senha = input("Senha: ")
print("Acesso concedido")

while True:
    cmd = input("> ")
    if cmd == "sair": break

Quando usar cada um

SituaçãoUsa
Percorrer lista/tupla/dictfor
Repetir N vezes conhecidofor + range
Repetir até condição mudarwhile
Loop infinito com breakwhile True
Ler até EOFfor linha in f
for i in range(10):
    if i == 3: continue # salta para a próxima
    if i == 7: break # sai do loop
    print(i)
// 04 — Padrões em texto

Regex com re

O módulo re serve para procurar, validar e extrair padrões em strings.

🔍

re.search

Primeira ocorrência
import re

texto = "email: joao@exemplo.com"
m = re.search(r"\w+@\w+\.\w+", texto)
if m:
    print(m.group())
# joao@exemplo.com
📋

re.findall

Todas as ocorrências
texto = "ana@x.com, rui@y.pt"
emails = re.findall(r"\w+@\w+\.\w+", texto)
print(emails)
# ['ana@x.com', 'rui@y.pt']

Símbolos essenciais

SímboloSignifica
\dUm dígito
\wLetra, dígito ou _
\sEspaço, tab, newline
.Qualquer caractere
*0 ou mais
+1 ou mais
?0 ou 1
{3}Exatamente 3
[abc]a, b ou c
^ $Início / fim da string
(...)Grupo de captura

Exemplo: validar NIF

import re

def nif_valido(nif):
    return bool(re.search(r"^\d{9}$", nif))

print(nif_valido("123456789")) # True
print(nif_valido("12345")) # False

Exemplo: extrair horas de um log

log = """[10:23:45] Login OK
[10:24:01] Erro 500
[10:25:30] Login OK"""

horas = re.findall(r"\[(\d{2}:\d{2}:\d{2})\]", log)
print(horas) # ['10:23:45', '10:24:01', '10:25:30']
⚠️
Usa raw strings

re.search("\d+", texto) funciona mas é arriscado. Usa re.search(r"\d+", texto) — o r evita problemas com o caractere \.

// 05 — Conjuntos

set

Um set é uma coleção sem ordem e sem elementos repetidos. Serve para garantir unicidade e testar pertença rapidamente.

frutas = {"maçã", "banana", "pera", "maçã"}
print(frutas) # {'maçã', 'banana', 'pera'}

Operações de conjuntos

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b) # união → {1,2,3,4,5,6}
print(a & b) # interseção → {3,4}
print(a - b) # diferença → {1,2}
print(a ^ b) # dif. simétrica → {1,2,5,6}

add, remove, discard, update

s = {1, 2, 3}
s.add(4) # {1,2,3,4}
s.remove(2) # {1,3,4} — erro se não existir
s.discard(99) # não dá erro se não existir

s.update([3, 4, 5]) # junta outro iterável
# s.update modifica no lugar, devolve None

List vs Set

listset
OrdemSimNão
DuplicadosSimNão
Acesso por índiceSimNão
Procura inLenta O(n)Rápida O(1)
Caso de usoSequência ordenadaUnicidade

Exemplo: palavras únicas de um texto

texto = "o gato viu o cão e o cão viu o gato"
palavras = set(texto.split())
print(palavras) # {'o', 'gato', 'viu', 'cão', 'e'}
print(len(palavras)) # 5 palavras únicas
// 06 — Tudo junto

Exemplo integrado

Ler um ficheiro de log, extrair emails únicos e guardar num novo ficheiro. Repara como todos os conceitos aparecem juntos.

import re

def extrair_emails(ficheiro_entrada, ficheiro_saida):
    try:
        with open(ficheiro_entrada, "r", encoding="utf-8") as f:
            texto = f.read()
    except FileNotFoundError:
        print("Ficheiro de entrada não existe.")
        return

    # findall devolve lista; set remove duplicados
    emails = set(re.findall(r"[\w.+-]+@[\w-]+\.[\w.]+", texto))

    try:
        with open(ficheiro_saida, "w", encoding="utf-8") as f:
            for email in sorted(emails):
                f.write(email + "\n")
        print(f"{len(emails)} emails únicos guardados.")
    except PermissionError:
        print("Sem permissão para escrever.")

extrair_emails("log.txt", "emails.txt")
🧠
Conceitos usados

try/except → tratar ficheiros inexistentes · with open → ler e escrever com segurança · for → iterar sobre o set ordenado · re.findall → extrair padrões · set → remover duplicados.
