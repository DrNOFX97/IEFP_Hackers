Aula 01 Fundamentos e rede do computador

Glossário

LAN
Local Area Network — rede local, limitada a um edifício ou campus (ex: rede de uma escola ou escritório).
WAN
Wide Area Network — rede de longa distância que interliga várias LANs (ex: a Internet).
NIC
Network Interface Card — placa de rede (com fios ou sem fios) que liga o computador ao meio físico.
Switch
Equipamento que interliga dispositivos na mesma rede local, encaminhando frames com base no MAC.
Router
Equipamento que interliga redes diferentes e encaminha pacotes entre elas (acesso à Internet).
AP
Access Point — ponto de acesso sem fios que permite a ligação Wi-Fi à rede local.
RJ45
Conector standard de 8 contactos usado em cabos de par entrançado (Ethernet).
IP
Internet Protocol — endereço lógico que identifica um dispositivo na rede (IPv4: 4 octetos).
Máscara de sub-rede
Define que parte do IP é rede e que parte é host (ex: 255.255.255.0 → /24).
Gateway
Porta de saída para outras redes; normalmente o router da LAN.
DNS
Domain Name System — traduz nomes de domínio em endereços IP.
DHCP
Dynamic Host Configuration Protocol — atribui automaticamente IP, máscara, gateway e DNS.
MAC
Media Access Control — endereço físico único da placa de rede (6 octetos hexadecimais).
Par entrançado
Cabo de cobre com 4 pares de fios torcidos (UTP/STP); categorias Cat5e, Cat6, etc.

LAN vs WAN

LAN
  • Alcance limitado (casa, escritório, escola)
  • Alta velocidade, baixa latência
  • Administração local
  • Exemplos: rede doméstica Wi-Fi, rede de um departamento
WAN
  • Cobertura geográfica vasta
  • Velocidade variável, maior latência
  • Operadores de telecomunicações
  • Exemplos: Internet, ligação entre filiais de uma empresa

Componentes principais

  • NIC — liga o computador à rede (com fios ou sem fios)
  • Switch — liga equipamentos na mesma rede local; trabalha com endereços MAC
  • Router — liga redes diferentes e dá acesso à Internet; trabalha com endereços IP
  • AP (Access Point) — dá ligação sem fios (Wi-Fi) à rede local

Cablagem

Meio: cobre (par entrançado UTP/STP) · Conector: RJ45

Categorias comuns:

  • Cat5e — até 1 Gbps, 100 m
  • Cat6 — até 10 Gbps (55 m) / 1 Gbps (100 m)

Aula 02 Camadas e sistema binário

Porquê pensar por camadas?

Analogia da carta: o conteúdo (mensagem) é colocado num envelope (endereço), que vai para um saco postal (transporte), depois para um camião (rede física). Cada “camada” trata apenas da sua responsabilidade. O mesmo acontece nas redes: cada camada acrescenta ou remove a sua própria informação (encapsulamento).

Modelo OSI (7 camadas)

7AplicaçãoInterface com o utilizador / aplicações (HTTP, FTP, DNS…)
6ApresentaçãoTradução, compressão e encriptação dos dados
5SessãoEstabelece, gere e termina sessões entre aplicações
4TransporteEntrega fiável (TCP) ou rápida (UDP); portas; segmentação
3RedeEndereçamento lógico (IP) e encaminhamento entre redes
2Ligação de dadosEndereçamento físico (MAC); frames; deteção de erros
1FísicaBits no meio físico (cabo, rádio, fibra)

Encapsulamento

Data → Segment (Transporte) → Packet (Rede) → Frame (Ligação de dados) → Bits (Física)

Na receção a ordem é inversa: bits → frame → packet → segment → data.

Sistema binário e IP

  • Bit — unidade mínima (0 ou 1)
  • Byte / octeto — 8 bits
  • Endereço IPv4 = 4 octetos (ex: 192.168.1.20)
  • Pesos dos 8 bits: 128 64 32 16 8 4 2 1
  • Limites de um octeto: 00000000 = 0 … 11111111 = 255 (256 valores)

Conversão decimal → binário (subtração dos pesos)

Exemplo: 192

192 ≥ 128? Sim → 1  (192−128=64)
 64 ≥  64? Sim → 1  (64−64=0)
  0 ≥  32? Não → 0
  0 ≥  16? Não → 0
  0 ≥   8? Não → 0
  0 ≥   4? Não → 0
  0 ≥   2? Não → 0
  0 ≥   1? Não → 0
Resultado: 11000000

Conversão binário → decimal (soma dos pesos ativos)

Exemplo: 10101100

1×128 + 0×64 + 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 0×1
= 128 + 32 + 8 + 4 = 172

Exemplo completo de IP

192.168.1.20  →  11000000 . 10101000 . 00000001 . 00010100

Operação AND bit a bit

Tabela verdade: o resultado só é 1 quando ambos os bits são 1.

Aplicação prática: IP AND máscara = endereço de rede

IP:      192.168.1.20   →  11000000.10101000.00000001.00010100
Máscara: 255.255.255.0  →  11111111.11111111.11111111.00000000
AND:     192.168.1.0    →  11000000.10101000.00000001.00000000

Aula 04 Subnetting

Fórmulas-chave

  • Número de subnets = 2b  (b = bits emprestados à parte de host)
  • Número de hosts por subnet = 2n − 2  (n = bits de host restantes; −2 = network + broadcast)
  • Salto (block size) = 2(bits de host)

Identificar a que subnet pertence um host

Com máscara /26 (salto 64), o host 192.168.10.100:

  • 0–63 → subnet 0
  • 64–127 → subnet 1 ← pertence aqui (Network 192.168.10.64)
  • 128–191 → subnet 2
  • 192–255 → subnet 3

Método rápido: dividir o último octeto pelo salto e arredondar para baixo → 100 ÷ 64 = 1 (resto 36) → subnet 1.

Aula 07 O caminho dos dados

Funções essenciais

DNS
Traduz nomes de domínio em endereços IP.
DHCP
Atribui automaticamente IP, máscara, gateway e DNS.
Gateway
Saída para outras redes (normalmente o router).
ARP
Traduz IP em MAC dentro da rede local.
ICMP
Diagnóstico e relato de erros (usado pelo ping).

Percurso de um pedido (ordem)

  1. DNS traduz o nome (ex: www.exemplo.pt) no IP de destino
  2. O computador aplica a máscara para verificar se o destino é local
  3. Se não for local → envia o pacote para o gateway
  4. Os routers encaminham salto a salto até ao destino

Tabela de routing e rota mais específica

Exemplo de tabela:

TCP vs UDP

TCP
  • Entrega fiável e ordenada
  • Reenvio em caso de perda
  • Handshake (ligação estabelecida)
  • Usar para: ficheiros, páginas web, email
UDP
  • Envio rápido, sem garantia
  • Sem reenvio nem ordem
  • Sem handshake
  • Usar para: vídeo em direto, DNS, jogos

Conceitos-chave

Socket
Combinação IP + porta que identifica uma extremidade de uma ligação.
Three-way handshake
Processo de estabelecimento TCP: SYN → SYN-ACK → ACK.
Firewall
Filtra tráfego segundo regras (permite ou bloqueia portas/protocolos/IPs).

Segurança e cablagem — Verdadeiro / Falso

V Encriptação torna os dados ilegíveis a quem não está autorizado.
F Cabo CCA é recomendado para PoE. (Não — o cobre puro é o recomendado; CCA tem maior resistência e aquece.)
V O firewall filtra o tráfego, permitindo apenas o que está autorizado.
F Usar a mesma password em todos os serviços é boa prática.
V A segmentação em VLANs ajuda a isolar e proteger a rede.

— Protocolos em detalhe

HTTP / HTTPS
Transferência de hipertexto (páginas web). O HTTPS acrescenta encriptação (TLS) sobre o HTTP.
FTP / FTPS
Transferência de ficheiros. Utiliza duas ligações TCP (controlo + dados). O FTPS acrescenta segurança (TLS).
SSH
Shell remoto seguro. Exemplo prático: ligação Windows → Debian na porta 22 (ssh utilizador@ip).
DNS
Tradução de nomes em IPs. Analogia: lista telefónica da Internet.
DHCP
Atribuição automática de IP, máscara, gateway e DNS ao cliente.
SMTP
Protocolo de envio de email (Simple Mail Transfer Protocol).
POP3
Descarrega o email do servidor e remove-o (pensado para um só dispositivo).
IMAP
Mantém o email sincronizado no servidor (nuvem) entre vários dispositivos.
TCP
Entrega fiável e ordenada, com reenvio em caso de perda de segmentos.
UDP
Envio rápido sem garantia de entrega nem de ordem; sem handshake.
IP
Endereçamento único de cada dispositivo; opera na camada 3 do OSI (Rede).
ICMP
Diagnóstico e relato de erros. Sem autenticação (pode ser usado em ataques). Base do ping.
ARP
Traduz IP em MAC na rede local. Processo: pergunta em broadcast → resposta em unicast. Comando: arp -a.
NTP
Sincronização de relógios via UTC. Porta UDP 123.
