nc -lvnp 4444Listener (receber reverse shell)
nc -zv IP 1-1000Port scan rápido

John the Ripper Post

Hashcat Post
hashcat -m 0 h.txt wl.txtMD5 + wordlist
hashcat -m 1000 h wlNTLM (Windows)

hashcat --show h.txtVer resultados
hashcat -m 0 --example-hashesExemplos de hash MD5
